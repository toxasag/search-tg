## 🌟 Основные возможности

- 🔎 **Агрегатор мульти-каталогов**: Одновременный сбор данных в реальном времени из **8+ публичных каталогов Telegram** (`tgsearch`, `tgramcat`, `tgramsearch`, `waybien`, `lyzem`, `TG-Cat`, `Catalog Telegram`, `TGLib`).
- 🤖 **Полная защита от ботов**: Автоматическое распознавание и отсечение ботов (`isBotTarget`) на всех этапах — при парсинге, ручном импорте и сохранении в базу. В базу попадают только живые каналы и группы.
- 🎯 **Интеллектуальный движок релевантности и антиспама**:
  - Строгая проверка **совместной встречаемости геопозиции и ниши** (например, по запросу `"ремонт пхукет"` обязательно наличие и темы ремонта, и локации Пхукет; случайные байкерские клубы Пхукета или ремонтные каналы Москвы и Батуми автоматически отсекаются с оценкой 0).
  - Фильтр конфликта локаций (Negative Geo Clash): если в запросе указан Пхукет, а канал явно относится к Москве или Батуми, он отклоняется.
  - Разбиение составных запросов, стемминг, синонимические ряды и автоматическая блокировка адалта, эскорта и спама.
- 🗄️ **Глобальная база каналов (`#database`)**:
  - Просмотр, поиск, фильтрация и инспекция всей накопленной базы Telegram-ресурсов (более 26 000 записей).
  - Точный поиск с выбором области: **«Везде»**, **«В названии»** или **«В описании»**.
  - Быстрые фильтры по типу: **Все**, **Каналы**, **Группы и чаты**, **Приватные** (инвайт-ссылки), **Неизвестные**.
  - Массовое выделение и выгрузка в **TXT ссылки**, **TXT отчёт**, **CSV** (с поддержкой Excel и BOM UTF-8) и **JSON**.
- ⚡ **Фоновое обогащение и проверка типов**:
  - Автоматический сбор превью Telegram (`t.me/<username>`).
  - Определение аватаров, количества подписчиков/участников, описаний и типов сообществ (канал, чат, приватный) с ограничением частоты запросов.
- 📥 **Массовый импорт ссылок**: Загрузка сотен и тысяч ссылок (`t.me/...`, `tg://...`), мгновенная дедупликация и фоновое обогащение данных.
- 🔒 **Многопользовательская безопасность и роли (RBAC)**:
  - Разделение прав (Владелец системы и Пользователи).
  - Аутентификация на сессионных HTTP-only куках с защитой от CSRF.
  - Панель администратора для управления пользователями и журнал аудита действий.
- 🐳 **Готовый деплой в Docker и на VPS**:
  - Оптимизированная многоэтапная сборка Docker.
  - Готовый `docker-compose.yml` для изолированного запуска за Nginx / Nginx Proxy Manager с автоматическим SSL-сертификатом Let's Encrypt.

## 🚀 Быстрый старт (Локальная разработка)

### Требования
- **Node.js** 22.0.0 или новее
- **npm** 10.0.0 или новее

### 1. Клонирование репозитория
```bash
git clone https://github.com/toxasag/search-tg.git
cd search-tg
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка переменных окружения
Скопируйте шаблон `.env.example` в `.env`:
```bash
cp .env.example .env
```
Задайте учетные данные первого администратора в `.env`:
```env
# Первичный аккаунт владельца (пароль от 12 символов)
BOOTSTRAP_OWNER_EMAIL="owner@example.com"
BOOTSTRAP_OWNER_PASSWORD="your-strong-bootstrap-password"

# Порт приложения и путь к базе данных
PORT=3000
DATABASE_PATH="./data/search-tg.sqlite"
NODE_ENV="development"
```

### 4. Запуск тестов
```bash
npm test
```

### 5. Запуск сервера разработки
```bash
npm run dev
```
Откройте [http://localhost:3000](http://localhost:3000) в браузере и войдите под учетной записью администратора.

## 🎯 Движок релевантности и фильтрации

При сложных составных запросах (например, `"ремонт пхукет"` или `"бизнес тайланд"`) обычный поиск часто забивается нерелевантными результатами.

Встроенный движок решает эту проблему:
1. **Семантическая классификация токенов**:
   - **Гео-локации**: `пхукет`, `тайланд`, `бангкок`, `москва`, `дубай`, `бали` и др.
   - **Тематики и ниши**: `ремонт`, `бизнес`, `недвижимость`, `крипта`, `визы`, `работа` и др.
   - **Форматы**: `чат`, `канал`, `группа`, `клуб`.
2. **Строгая совместная встречаемость (Co-occurrence)**:
   - Канал обязан содержать **и** тему, **и** указанную геолокацию. Канал мотоциклистов Пхукета будет отклонен при поиске ремонта, равно как и строительный канал Москвы.
3. **Защита от чужих городов (Negative Geo Clash)**:
   - Если в запросе город $A$, а в описании канала указан город $B$ ($A \ne B$), каналу присваивается 0 баллов и он отсекается.
4. **Фильтрация спама и адалта**:
   - Автоматический отсев порнографии, эскорта, казино и дорвеев.

## 🗄️ Раздел «Глобальная база»

Интерфейс **Глобальная база** предназначен для удобного мониторинга и выгрузки всей собранной информации:

1. **Гибкий поиск по ключевым словам**: поиск по **всем полям**, только по **названию** или только по **описанию**.
2. **Фильтрация по типам сообществ**:
   - 📢 **Канал**
   - 👥 **Группа / Чат**
   - 🔒 **Приватный** (ссылки-приглашения `t.me/+...` или `t.me/joinchat/...`)
   - ❓ **Неизвестно**
3. **Экспорт в 4 формата**:
   - **TXT ссылки**: чистый список ссылок Telegram (по одной в строке) для заливов и рассылок.
   - **TXT отчёт**: подробный читаемый отчет со всеми метаданными.
   - **CSV**: табличный формат с экранированием по RFC 4180 и BOM UTF-8 для корректного открытия в Excel.
   - **JSON**: массив объектов для автоматизации и интеграций.
4. **Фоновое дообогащение**:
   - Возможность запустить фоновый воркер для проверки типов и обновления аватаров/подписчиков по всем неразмеченным каналам.

## 🐳 Развертывание на VPS через Docker

### Инструкция по деплою
В репозитории подготовлен промышленный многоэтапный `Dockerfile`:

```bash
# 1. Склонируйте проект на вашем VPS сервере
git clone https://github.com/toxasag/search-tg.git /opt/search-tg
cd /opt/search-tg

# 2. Настройте файл конфигурации .env
cp .env.example .env
nano .env

# 3. Соберите и запустите контейнер
docker compose up -d --build
```

### Настройка Nginx Proxy Manager
При использовании **Nginx Proxy Manager**:
- Forward Hostname: `search-tg`
- Forward Port: `3000`
- Включить галочки: `Websockets Support`, `Block Common Exploits`
- SSL: Выпустить сертификат Let's Encrypt, включить `Force SSL` и `HTTP/2 Support`.

Конфигурация для классического **Nginx**:
```nginx
server {
    server_name tgsearch.team-big.ru;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 300s;
    }
}
```

## 🔒 Безопасность и хранение данных

- **Отсутствие секретов в Git**: Файлы `.env`, базы данных SQLite (`*.sqlite`), файлы сессий (`*.session`) и логи исключены через `.gitignore`.
- **Резервное копирование базы**: Для резервного копирования SQLite используйте онлайн-команду `sqlite3 data/search-tg.sqlite ".backup backup.sqlite"`, а не прямое копирование файла во время работы WAL-журнала.
- **Безопасность сессий**: Пароли хэшируются стойкими криптографическими алгоритмами, сессии защищены безопасными куками с флагами HttpOnly и SameSite.
