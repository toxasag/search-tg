## 1. Обзор проекта

Веб-приложение для поиска Telegram-каналов/групп через сторонние каталоги-агрегаторы
и извлечения прямых `t.me`-ссылок.

**Стек:**
- Фронт: React 19 + TypeScript + Tailwind CSS v4
- Бэк: Express + Vite middleware (единый процесс `tsx server.ts`, порт 3000)
- Парсинг: Cheerio (CSS-селекторы) + Google Gemini (`gemini-3.5-flash`) как AI-фолбэк
- Данные хранятся на клиенте в localStorage

**Запуск:** `npm run dev` → http://localhost:3000
**Требует:** `GEMINI_API_KEY` в `.env` (нужен только для AI-режима и AI-фолбэка)

## 3. Что реализовано (по коду)

### Бэкенд — server.ts
- 🟡 `GET  /api/health` — статус + время сервера
- 🟡 `POST /api/search` — постраничный обход каталогов (батчи по 5 страниц, стаггер 250 мс),
  парсинг карточек, дедупликация по username/tg-ссылке/detailUrl, сбор статистики,
  авто-остановка при 3 пустых страницах подряд или полном дубле батча.
  ([server.ts:711](server.ts#L711))
- 🟡 `POST /api/extract-link` — извлечение прямой t.me-ссылки с детальной страницы
  (селекторы + regex, фолбэк на AI), плюс поиск «похожих каналов».
  ([server.ts:1121](server.ts#L1121))
- 🟡 Два режима парсинга: `fast` (Cheerio-селекторы) и `ai` (Gemini). В `fast` при пустой
  1-й странице — авто-фолбэк на AI, если задан `GEMINI_API_KEY`.
- 🟡 Спец-парсеры для tgsearch / tgramcat / tgramsearch + generic-фолбэк.
- 🟡 `detectChatType` — эвристика типа: channel / group / closed / unknown.
- 🟡 `fetchWithHeaders` — ретраи, обработка 429, таймаут 15 с.

### Фронт — src/App.tsx + компоненты
- 🟡 Таблица результатов (Live Feed), пагинация на клиенте.
- 🟡 Фильтры: текст, источник, статус извлечения, тип чата.
- 🟡 Мульти-запрос (разделение по `, ; \n`), режим «Append results».
- 🟡 Bulk-извлечение ссылок с настраиваемой задержкой (1.0–4.0 с).
- 🟡 Экспорт CSV / JSON, «Copy all links».
- 🟡 История запросов, статистика по источникам, всё в localStorage.
- 🟡 [Header.tsx](src/components/Header.tsx) — статус сервера (health-poll каждые 30 с).
- 🟡 [LogsPanel.tsx](src/components/LogsPanel.tsx) — консоль логов операций.
